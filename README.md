# Basic-Tools
This repository stores scripts that are useful for many scripts

readers.py
  This script defines functions that read in data. Import this file as a module to use functions in this file.


calculators.py
  This script defines functions that do basic calculation in Seismology. Import this file as a module to use functions in this file.


file_processors.py
  This script defines functions that do works with processing files.


picker_pal.py
  The STA/LTA phase picker from PAL catalog constructing workflow.


plots.py
  Common plotting functions.


writers.py
  This script defines functions that output data into formatted files.
